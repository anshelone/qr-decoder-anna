# QR Decoder — Анна Шелестова 💗

Это веб-приложение, которое можно установить на iPhone как отдельную иконку на экране «Домой».

## Что умеет
- сканировать QR-код камерой iPhone;
- читать QR-код с фотографии;
- декодировать QR-коды сайта проекта;
- поддерживать: без сжатия, zlib, lzma, bz2, brotli, zstandard, lz4;
- копировать результат и открывать ссылки;
- работать в стиле розового сайта проекта.

## Важно
На Windows/Huawei Xcode не нужен. Приложение запускается как PWA (web app) в Safari. Для камеры на iPhone нужен HTTPS, поэтому проект нужно разместить на хостинге.

## Локальный запуск
```text
python -m pip install -r requirements.txt
python app.py
```

## Публикация
Для простого варианта можно использовать Render. Build Command:
`pip install -r requirements.txt`

Start Command:
`gunicorn app:app`

После публикации открой URL на iPhone в Safari → Поделиться → На экран «Домой» → включить «Открывать как веб-приложение» → Добавить.
